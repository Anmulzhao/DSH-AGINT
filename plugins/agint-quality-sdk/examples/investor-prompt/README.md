# investor-prompt@0.1.0

> Generated by `agint-prompt-init` (preset=investor).

**Description**: Investor-oriented research summarization prompt with risk annotation.

**Kind**: system

**Variables** (declared, Frozen):
- `user` (string, required=true) — User-side vars (identity)
- `subject` (string, required=true) — Subject being researched
- `risk` (enum, required=true) — Risk tag
- `max` (string, required=true) — Output limit

**Regression tests**: 5 (Phase 4 std: ≥5)

## Quick use

```js
import { renderPrompt } from 'agint-quality-sdk';
import { readFile } from 'node:fs/promises';
const manifest = JSON.parse(await readFile('manifest.json', 'utf8'));
const templateText = await readFile('template.md', 'utf8');
const out = renderPrompt({ templateText, manifest, values: {"user":{"identity":"老板"},"subject":{"name":"AGINT v0.4.0 release"},"risk":{"level":"low"},"max":{"words":"600"}} });
console.log(out);
```
