## 2. 拍板时需要一并确认的三条配套约束

1. **`gold ∩ heldout` 的 id 交集必须为 0**，否则 `verifyBaseline()` 直接判 `CORRUPT`。
   `--check` 已把这项做成硬校验。
2. **gold 绝不拿来调参**。一旦拿金标调参，验证集即退化为训练集，一致率失去意义。
3. **verify 里的样本绝不标 `GOLD`/`HELDOUT`**。`verifyBaseline()` 遍历三份集合的
   所有 samples 统计 `usableFrozenLabels`，标了会把验证样本混进可用标签分母。
   `--check` 已把这项做成硬校验。

⛔ 另外：`frozenBy` / `frozenAt` 必须由人逐条填。脚本把
`agent / system / auto / script / ai / assistant / llm / ''` 等一律判为系统代签并拒绝密封。
