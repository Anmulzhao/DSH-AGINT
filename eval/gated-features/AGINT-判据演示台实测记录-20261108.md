## 1. 做出来的是什么

一份**自包含 HTML 单页**（零外部依赖、浅色/深色主题自适应、不连任何后端、不发起任何写入），
用大白话讲清三件事，并给一个可交互实验台：

1. **为什么日报分数不算数** —— 80.3 → 100 是公式自评，存在自我参照 / Goodhart 问题；
   能力图谱只覆盖 1 个 ISO 周、人工标注 0 条 ⇒ 判定 `NOT_COMPARABLE`，拒绝给方向一致率。
2. **科学合理的判据长什么样** —— 外置、可复现、可证伪、可撤销，每条对应仓库里真实存在的代码。
3. **五道闸实验台** —— 五个下拉框直接对应 `bin/autonomous-write-gate.mjs` 的真实条件，
   可拨到「载入今天真实状态」「恢复默认」「试着真的写一次」，实时看放行/拦截；
   并明确画出三层：**判据 → 五闸允许 → 真的落盘**，⛔ 允许 ≠ 已写入。

页面 **44 个数字全部由实跑 JSON 绑定**，无手写数字；页面底部自带「数据自检」提示。

## 4. 测试中查出的两件事（都已处理）

1. **文档读数漂移**：11-07 报告写日报分数末值 99.9，本次重跑 `score-vs-evidence.mjs --json`
   实为 **100**（Δ=19.7）。演示台一律采用本次实跑值，并在页面注明差异来源。
   ⇒ 以后引用分数必须现跑，不能沿用历史报告数字。
2. **本沙箱无法用 Chrome 无头渲染**：`/usr/bin/google-chrome` 连 `--version` 都 SIGTRAP 崩溃
   （EXIT=133，干净环境 `env -i` 同样崩），截图 / `--dump-dom` 均不可用。
   ⇒ 改用 Node `vm` + 最小 DOM stub 真执行页面内联脚本，并把页面判定与真实闸门模块逐组对拍，
   验证力度比截图更强（能测交互逻辑，不只是看外观）。

## 5. 边界（必须一起看）

- ⛔ 这批 `GOLD` 是**运营者授权 · agent 执行 · 非人类验证**的机械真值，
  `frozenBy` 明写 `NOT human-validated`、`humanValidated:false`，并已披露**构造期自参照**。
  **不能据此说「AGINT 变聪明了 / 能力提高了」**；`capabilityConclusion` 恒 `null`。
- ⛔ 五闸 5/5 只到「允许投递候选」，离真的写入还差真实服务窗口；判定为**不予放行**，
  生产写入恒 0，没有伪造 `--ack-service-window`。
- 本页与本报告均为**只读演示与记录**，不改仓库、不发版、不 redeploy。
