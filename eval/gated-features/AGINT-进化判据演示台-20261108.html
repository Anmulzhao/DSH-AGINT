01为什么日报那个分数不算数

你之前问「智能水平能有多高，是不是就是每日日报分数」。答案是否定的，而且理由很具体。

分数涨了，但没证明什么
— → —近 — 周 · Δ—

这个分数由 noise / confidence / redundancy / bloat 四个数字套固定公式算出，评分链路完全不用大模型，也不读系统真实能力。公式算得越漂亮，只说明输入更合公式胃口。

自己出题、自己判、自己报
自我参照

题是系统侧的、分是系统算的、报是系统发的。这种情况下涨分可以靠「把尺子磨顺」实现，不需要真的变强。经济学里管这叫 Goodhart：一旦指标变成目标，它就不再是好指标。

换一把尺子：从「系统自评」搬成「外部判据」

关键区别不是「算得更准」，而是被评对象碰不到判据：题在外面、答案密封、跑分的是独立校验器，而且事先声明什么算进步，事后可以被打脸。

02一份科学合理的判据长什么样

四条原则，每条都对应仓库里真实存在的东西，不是设想。

1 · 外置判据不读任何分数字段，不由被评对象生成或改写。三份冻结集一次性密封，运行时只能读。实现：eval/capability-baseline/sets/{gold,verify,heldout}.json + contentHash
2 · 可复现每条 PASS / REJECT 由确定性校验器当场实跑得出，不硬编码；任何第三方重跑得到同一答案。实现：23 条断言，node bin/capability-baseline-mechanical.mjs --verify
3 · 可证伪事先写清「预计下周某计数从 0 变成 1」，下周重读同一张表算实际值；不符就如实记为预测失败，不解释成能力退步。实现：predictedDelta=+1 与 predictedDeltaSource，下一 ISO 周对拍 actualDelta
4 · 可撤销默认拒绝。要动真格写入必须五道闸全过；人随时能否决，24 小时内可撤回。实现：defaultDeny + 五闸 + vetoWindowHours=24 + --veto

这四条合起来的效果：系统再怎么优化自己，也改不了判据；判据说没通过，就是没通过。这才是「判断进化」，而不是「播报进化」。

05最后一盏灯为什么没亮

五道闸全绿，为什么还是「生产写入 0」？因为「允许」和「真的落盘」中间还隔着一个物理条件，现场取证发现它不成立。

1
服务在另一个进程房间，停不掉也重启不了

3080 端口仍返回 401（说明服务活着），但当前会话的进程表里看不到它 —— 服务与本会话分属不同的 PID 命名空间。没有停机窗口，就没有安全的写入窗口。

2
写了也会被覆盖，而且面板根本看不见

服务内存里持有一整份提案表；从外面直接改文件，服务下次落盘会整体覆写。面板读的是服务内存态，所以这条写入既留不住、也显示不出来。只拿「盘上回读成功」当证明是假绿。

3
服务里没有「新建候选」的入口

面板唯一的写接口只能修改已有记录的状态，记录不存在就返回空；dsh 也没有通用的工具调用路由。要写，得先另开一轮加接口并重启服务。

4
人工标注仍然是 0 条

判尺标定需要人来判断「这条日报到底准不准」，这件事我不代填 —— 系统自己给自己标注，又回到自评循环了。

所以我没有伪造「服务窗口已确认」这个人工声明。不写，是判据起作用的结果，不是链路坏了。能安全验证的都验证了：隔离域里真写 1 条并回读、生产哈希 6/6 不变。

06必须说清楚的边界（这一节最重要）

你让我「科学合理地做完」，那诚实就比好看重要。这批东西有一个必须写在明面上的降级。

这批「GOLD」不是人类验证过的金标

  • 它是运营者授权、由 agent 执行、非人类验证的机械真值：每题的 PASS / REJECT 由确定性校验器实跑得出，第三方重跑同解，密封后不可篡改。
  • 署名里明写 NOT human-validated，humanValidated: false，授权来源、执行者、降级语义全部记在 provenance 里，可审计、可回滚。
  • 构造期自参照：题目是系统侧依现有代码契约构造的，系统有可能挑自己容易通过的断言。这个局限已经写进文件，没有藏起来。
  • 因此 GOLD / HELDOUT 在这里只表示「外置于评分回路、可独立复现、密封不可篡改的判据」，不表示授权人工已验证 AGINT 能力。
所以：不能据此说「AGINT 变聪明了 / 能力提高了」。校验器里的能力结论字段恒为空（capabilityConclusion = null），这一批只证明「存在一组像样的外部判据」。

这不是把事情做砸了，而是不把「系统自己出题自己判」包装成人类金标 —— 那样外部锚定当场退化成系统自证，整个诊断要修的正是这个问题。

07还差什么，以及怎么放行

两条物理前置，一条归运行环境，一条归人。齐了之后是一条命令的事。

前置 ① · 运行环境

真正停掉 dsh web 拿到停机窗口；或者另开一轮新增服务内「新建候选」入口并重启服务。

前置 ② · 人
