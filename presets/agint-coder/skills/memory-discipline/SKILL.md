# 记忆纪律（Memory Discipline）

智进的长期记忆 = `memory_write` / `memory_search` / `memory_read` / `memory_stats` / `memory_forget_scan` 五个工具，数据存在宿主侧 `agint` 存储域，跨会话持久。

## 我是谁 / 边界

- 记忆存**原则**，不存知识：教训、不可逆决策、用户偏好、规律。知识进 wiki/文件。
- 记忆是**事实库**，不是对话记录。聊天记录由 Harness 会话日志全量保存，不需要写进记忆。
- 一条记忆 = 一句自包含的话。能合并的合并，能删的删（简洁 > 冗余）。

## 什么时候读（先搜再答）

- 回答涉及既往**教训、决策、偏好**时，先 `memory_search`（例如：配置排查、危险操作、用户风格、历史踩坑）。
- 用户纠正你，或你发现自己重复犯错时，搜一下是否已有对应教训。

## 什么时候写

| 场景 | 类型 | 必带 |
|---|---|---|
| 踩坑/禁止项（"以后不能这样做"） | `lesson` | **evidence**（工具+动作+位置，不写证据等于没写） |
| 不可逆决策（架构/配置/命名） | `decision` | 决策日期与理由 |
| 用户偏好（称呼、风格、作息） | `preference` | 来源 |
| 可复用的规律/模式 | `pattern` | 验证依据 |

写之前先 `memory_search` 查重：已存在 → 用 `id` 更新而不是新建。

## 证据规范

`evidence` 必须能复现：`tool=xxx action=yyy location=zzz`。禁止只写"已记录"而不附证据。

## 遗忘扫描

- `memory_forget_scan`（dry-run）可随时跑，看计划动作。
- 确认无误后加 `apply:true` 执行降级/清除。
- 不要为清理而清理；被替代/已解决的旧条目才值得清。

## 与准则层的关系

- 核心教训 → `lesson`（原则层）
- 方法/流程 → 准则（AGENTS.md 类文件）
- 知识/积累 → wiki（文件）

产出时先判断类型，别都往一处塞。
